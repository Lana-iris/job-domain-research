# 证据分级模型

## 定级前提
1. 只有实际打开并读到内容的页面才能参与 E1–E5 定级。
2. 只看到搜索结果标题/摘要 → 记为"线索（L0）"，不参与定级。
3. 转述页按转述页自身档位定级；原始材料不可达时不得抬升。
4. 一条信号至少有一个已读来源；否则不得进入 3–5 条信号。

## 来源优先级（高 → 低）
1. **一手材料**：官方公告、原始研究、监管或统计机构发布、企业自有披露。
2. **真实招聘信息**：在招岗位说明（含岗位职责与要求原文）。
3. **专业机构报告**：有方法论说明的调研与咨询报告。
4. **高质量媒体**：有署名、有原始链接的报道。
5. **聚合与转述**：仅为线索，**不得单独支撑结论**。

## 证据等级（E1–E5）
| 来源优先级 | 等级 | 含义 |
|---|---|---|
| 1 一手材料 | E1 | 官方公告 / 原始研究 / 监管或统计机构 / 企业自有披露 |
| 2 真实招聘信息 | E2 | 在招岗位说明（职责与要求原文） |
| 3 专业机构报告 | E3 | 有方法论的调研 / 咨询报告 |
| 4 高质量媒体 | E4 | 有署名、有原始链接的报道 |
| 5 聚合与转述 | E5 | 仅为线索，不得单独支撑结论 |

- 单条信号含多来源时：**定级**取**支撑核心结论的最高档来源**；**表述上限**取最弱必要来源（木桶效应）；子来源逐档标注。

## 结论强度不得超过证据强度
| 证据状况 | 允许的表述强度 |
|---|---|
| 多源独立 + 一手材料 | "趋势已确认" |
| 多源但同源转述 / 单一机构 | "方向可信，幅度待核" |
| 单一来源 / 样本有限 | "存在该迹象，不足以下判断" |
| 仅有推断 | "当前证据不足"，并写明需要什么证据 |

## 禁止
在没有新证据的情况下重新表述既有结论，使其看起来更确定。

## 混合来源信号（一条信号含多个来源）
1. **定级**：以**支撑核心结论的最高档来源**为信号主等级。
2. **表述上限**：取支撑该结论的**所有来源中最弱的一档**所允许的强度（木桶效应——不因掺入高档来源而整体抬升结论）。
3. **标注**：在信号内**逐档标注**每个子来源（名称 + 档位）。
