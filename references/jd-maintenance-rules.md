# 岗位数据维护规则（默认规格 · 技能默认）

> 本文件是**通用默认规格**：采集方式 / 匹配逻辑 / 权重公式 / 入库上限 / 失效清理 / 文件策略 / 与日报集成 / 合规 / 可达性 / 检索平台 / 公司梯队。
> **岗位域绑定**的内容只有**关键词集**，写在项目的 `research-state.md`。
> 如需为本岗位域调整本文件任一默认，可在 `research-state.md` 追加**覆盖项**。

## 一、采集方式
- 使用公开索引检索（WebSearch 类，非爬取）；**不登录、不突破登录墙**。
- 覆盖缺口 = 未被搜索引擎收录的登录墙岗位，属正常缺失。

## 二、匹配逻辑
- 关键词集（见 `research-state.md`）子串命中 → 进候选池；去重键＝**公司 + 职位 + 城市**。
- “高信号”露出标签由 **综合优先级分 + 契合度 + 可达性** 共同决定。
- 对高信号岗位提炼：**JD → 能力 → 作品集**（即“真实招聘市场正在付费的能力证据”）。

## 三、权重公式（默认，可覆盖）
综合优先级分 = 100 × (0.30R + 0.28C + 0.22F + 0.10Ci + 0.10A)

| 维度 | 符号 | 权重 | 取值 |
|---|---|---|---|
| 时效 | R | 0.30 | ≤7 天=1.0；8–30 天=0.75；31–90 天=0.5；>90 天=0.3；未知=1.0 |
| 公司 | C | 0.28 | C = 0.6×行业分 + 0.4×梯队分（见 §十一） |
| 契合 | F | 0.22 | 契合度(1–5) / 5 |
| 城市 | Ci | 0.10 | 深/广/杭=1.0；北/上/港=0.9；远程=0.9；其他=0.5 |
| 可达性 | A | 0.10 | 当前可达性(1–5) / 5 |

- 综合优先级分仅用于**内部**高信号露出与排序，**不作为对外的精确排名**。
- 分析时**分别观察三视角**（**定性，不参与打分**）：**Market Signal**（市场为何种能力付费）/ **Immediate Opportunity**（≈当前可达性，能否进入）/ **Portfolio Benchmark**（需用什么产出物证明）。**库的排序仍按综合优先级分**。
- 城市/行业/梯队等具体取值属**默认**，可按岗位域覆盖。

## 四、入库上限（默认）
- 每日高信号岗位 **≤ 10 条**，**宁缺毋滥**。

## 五、失效清理
- 满足任一即移入「JD历史·已失效」：截止日期已过 / 来源显示已关闭·招满 / 最后发现日期距今 >14 天未再发现。
- 每次扫描刷新“最后发现日期”。

## 六、文件策略
- 单本累积；按**去重ID**更新（去重键＝公司 + 职位 + 城市；同岗多平台合并一行，保留最优来源并注明全平台）。

## 七、与日报集成
- 岗位库随每日信号日报更新；日报中发现的招聘信号同步录入岗位库并标记 **【来自日报】**。
- 周度趋势视图由 O4 趋势报告承接。

## 八、合规
- 仅聚合公开信息；不爬登录墙、不存任何个人数据。

## 九、可达性
- 可达性 ≠ 契合度：可达性反映“以当前资历能否投进”，随产出物推进应逐月上升。

## 十、检索平台（默认示例）
- 覆盖：LinkedIn 领英 / 猎聘 Liepin / Indeed / 智联招聘 / 前程无忧 51job / 拉勾 / 各公司官网 careers 页。
- 未覆盖（建议手动补充）：脉脉（登录墙）、Glassdoor（登录墙）、BOSS 直聘（索引滞后，仅用户主动粘贴时以【用户补充】入册）。
- 发现新平台及时补充。

## 十一、公司梯队分（默认示例）
- 行业分：互联网/科技/AI/智造/金融科技=1.0；咨询/教育/医疗科技=0.8；传统=0.5。
- 梯队分：大厂=1.0；外企=0.9；中厂=0.8；创业小厂=0.6；未知=0.7。
- 大厂名单（梯队分=1.0 候选，默认示例，按岗位域维护）：
  - 官网可访问：美团 / 腾讯 / 字节跳动 / 阿里巴巴·淘天 / 蚂蚁集团 / 华为 / 百度 / 拼多多 / 京东 / 大疆
  - 未知待验证：快手 / 小米 / 网易 / 小红书 / 科大讯飞 / 滴滴 / 哔哩哔哩

## 数据字段
- 每条岗位含唯一 ID、结构化薪酬、时间戳（首次/最后发现）、岗位/职能专有能力要求、Market Signal、Portfolio Relevance、Portfolio Benchmark 等；字段定义见 `templates/jd-library.template.xlsx`。
